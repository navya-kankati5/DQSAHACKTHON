How DQSA works: The system captures network-flow characteristics such as packet size, flow duration, byte rate and inter-arrival time. DQSA processes these features and predicts the application category, service type and VPN status without inspecting encrypted payload content.

Application Identification: The dashboard provides a human-readable demonstration label based on the predicted traffic category. For example, STREAMING is displayed as YouTube.

Friend Devices: Authorized endpoint agents can report their own device connection metadata to the dashboard.

Privacy: The system does not inspect encrypted payload contents.
